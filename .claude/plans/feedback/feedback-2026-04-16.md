## QA 피드백 (외부)

### 1. 모드 구분 UI 명확성 부족 (우선순위: 중)
- **내용**: 인원기반 / 직접입력 2가지 방식의 차이가 불명확
- **타당성**: O — desc 텍스트가 짧아 구분 어려움
- **관련 파일**: `app/solo/setting/page.tsx:14-17`, `app/food/setting/page.tsx:15-18`, `components/flow/FlowSettingPage.tsx:68`

### 2. 후보에 없는 항목 선택 (우선순위: 낮음)
- **내용**: 볼링이 후보에 없는데 결과로 나옴
- **타당성**: 코드상 로직 버그 없음. enableRespin 자동 재회전으로 인한 사용자 혼동
- **조치**: #4 재회전 UI 개선으로 해결. 별도 수정 불필요

### 3. ContentShuffle 아이콘 크기 과도 축소 (우선순위: 높음)
- **내용**: 후보가 많아지면 아이콘이 너무 작아져 가독성 저하
- **타당성**: O — n=8일 때 37px, n=10일 때 28px (아이콘 11px)
- **관련 파일**: `components/ContentShuffle.tsx:119`
- **보완점**: overflow-x: auto는 셔플 게임 특성(컵 추적+클릭)과 충돌. 최소 크기 보장 + n≥7 시 shuffle 제외 검토

### 4. 룰렛 자동 재회전 UI 피드백 없음 (우선순위: 높음)
- **내용**: 한 번 돌렸는데 두 번 도는 경험. 의도된 기능이면 표시 필요
- **타당성**: O — enableRespin={true}에서 50% 확률 재회전, UI 피드백 전무
- **관련 파일**: `components/SpinWheel.tsx:66-75`, `components/flow/FlowRandomPage.tsx:187`
- **보완점**: 재회전 대기 600ms 동안 isSpinning=false → SPIN 버튼 재클릭 가능. 버튼 비활성화 처리 필요

### 5. 결과 이동 딜레이 부족 (우선순위: 높음)
- **내용**: 룰렛 완료 후 결과로 바로 이동. 잭팟 표시 시간 없음
- **타당성**: O — FlowRandomPage는 즉시 이동, SoloSpinPage는 800ms 딜레이. 불일치
- **관련 파일**: `components/flow/FlowRandomPage.tsx:78`
- **보완점**: setTimeout cleanup 필요 (unmount 시 router.push 방지). 슬롯 nearMiss와 합산 시 대기 시간 과다(~8.2초) 주의

### 6. 슬롯머신 부분 일치 미처리 (우선순위: 중)
- **내용**: 3개 릴이 항상 같은 값. 2개만 일치하는 재미 요소 없음
- **타당성**: O — resolvedIdx로 3개 릴 동일 정지. 항상 잭팟
- **관련 파일**: `components/SlotMachine.tsx:62-134, 168-172`
- **보완점**: nearMiss 연출 시 총 대기 시간 관리 (4초+1.2초+1.8초+결과 딜레이)

### 7. 하단 검정 원 표시 (우선순위: 높음)
- **내용**: 결정 완료 화면 & 대기실 화면에 하단 바 위에 검정색 동그라미 표시. 스크롤 시 따라 움직임 (갤럭시 Jump2)
- **타당성**: O — `PageLayout.tsx:17` paddingBottom과 `Toast.tsx:16` bottom이 `calc(32px + env(safe-area-inset-bottom))`로 고정. Android 디바이스별 safe-area 크기 차이로 인한 오버레이 문제
- **관련 파일**: `components/PageLayout.tsx:17`, `components/Toast.tsx:14-16`, `app/globals.css:28-33`

### 8. 토스트 메시지 위치 겹침 (우선순위: 중)
- **내용**: "공유 링크가 복사됐어요!" 토스트가 하단 바와 겹쳐 일부 가려짐
- **타당성**: O — Toast bottom 32px이 시스템 내비게이션 바와 겹침 가능
- **관련 파일**: `components/Toast.tsx:14-16`

### 9. 지도 버튼 디자인 불일치 (우선순위: 중)
- **내용**: 카카오 지도 / 네이버 지도 버튼 스타일이 페이지마다 다름
- **타당성**: O — `FlowResultPage.tsx:144-172` (흰 배경+테두리) vs `FlowDetailResultPage.tsx:131,149` (브랜드 색상). 동일 기능인데 스타일 불일치
- **관련 파일**: `components/flow/FlowResultPage.tsx:139-174`, `components/flow/FlowDetailResultPage.tsx:125-162`

### 10. "다시 선택" / "다시 돌리기" 문구 불일치 (우선순위: 낮음)
