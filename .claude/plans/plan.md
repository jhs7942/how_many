# 몇명이니 (HowMany) — PLAN B 요구사항 ver_4

> 마지막 업데이트: 2026-03-16 (ver_4 — "같이 결정" 플로우 추가, 투표 방 / 카카오 로그인·알람·Cron 제외)

## 컨텍스트

ver_3은 "혼자 결정" 단일 플로우로 단순화되었으나, 그룹이 함께 결정하는 니즈를 충족하지 못했다.
ver_4는 투표 방을 추가하여 "같이 결정" 플로우를 병행 제공한다.
카카오 로그인·알람·Cron job은 MVP에서 제외하며, 로그인 없이 참여 가능하다.
기존 "혼자 결정" 플로우는 그대로 유지.

---

## 1. 서비스 개요

| 목표 | 앱 실행 → 10초 안에 결정 |

## 2. 해결하려는 문제

- 모임에서 "어디 갈지" 단톡방 30분 토론 → 결국 아무거나
- 정보가 없어서가 아니라, 선택지가 너무 많아서 결정 못함
- 지도·리뷰·예약 앱을 오가며 피로 누적

**핵심 가치:** 검색 서비스가 아닌 결정 서비스

---

## 3. 사용자 흐름 (UX Flow)

### 혼자 결정 (기존 ver_3 유지)

```
앱 실행
  └─ Splash
      └─ 홈 (모드 선택)
            └─ [혼자 결정]
                  └─ 인원 선택 (2·3·4·5·6명+)
                        └─ 활동 돌림판
                              └─ 활동 결과
                                    ├─ 다시 돌리기
                                    ├─ 장소도 랜덤으로 정할게 → 장소 돌림판 → 장소 결과
                                    └─ 카카오톡 공유
```

### 같이 결정 (ver_4 신규)

```
홈 → [같이 결정]
  └─ 투표 방 생성 (후보 2~5개 입력 + 마감 시간 설정) — 로그인 불필요
        └─ 초대 링크 공유 (링크 복사)
              └─ 참여자: 링크 클릭 → 닉네임 입력 → 투표
                    └─ 투표 대기 화면 (마감까지 카운트다운)
                          └─ 마감 도달 → 결과 화면 (직접 접속)
```

## 5. 기능 상세

### 혼자 결정 — 인원 기반 활동 추천

```
2명  → 카페, 산책, 전시
3명  → 카페, 술집, 보드게임
4명  → 노래방, 보드게임, 방탈출, 볼링
5명+ → 고깃집, 술집, 볼링
```

### 혼자 결정 — 활동별 장소 유형

```
카페      → 분위기 카페, 테이크아웃, 디저트 카페
노래방    → 코인노래방, 일반노래방
보드게임  → 보드게임카페
볼링      → 볼링장
고깃집    → 삼겹살, 소고기, 곱창
방탈출    → 방탈출카페
술집      → 이자카야, 포차, 바
전시      → 미술관, 갤러리
산책      → 공원, 한강, 숲길
```

### 같이 결정 — 투표 방 기능

- 방장이 후보 2~5개 입력 + 마감 시간 설정 (최소 1시간 ~ 최대 7일) — 로그인 불필요
- 방 생성 시 고유 초대 링크 발급
- 링크 복사로 참여자 초대
- 참여자는 링크 클릭 → 닉네임 입력 → 투표 (1인 1표, 수정 불가)
- 마감 전 득표 수 비공개 (공정 투표)
- 방장도 투표 참여 가능
- 마감 후 결과 URL 직접 접속으로 확인
- 결과 링크 만료: 30일

### 같이 결정 — 결과 처리

- 1위 후보 강조 표시 + 득표 그래프
- 동점 발생 시 랜덤 결정 버튼 노출 (핵심 가치 유지)
- 방장 강제 종료(마감 앞당기기) 허용

### 랜덤 돌림판 (혼자 결정 공통)

- 인원 기반으로 추천된 활동 카테고리가 세그먼트로 표시
- 세그먼트 추가/제거 가능 (커스터마이징)
- 스핀 애니메이션 후 결과 강조

### 지도 연결

- 결과 화면에서 "근처에서 보기" 클릭 시 카카오/네이버 지도 새 탭
- 장소 DB 자체 구축 없음 (지도 앱 연결로 대체)

### 공유 기능

- 카카오톡 공유 (Kakao JS SDK)
- 인앱브라우저에서도 동작
- 클립보드 복사 폴백

## 7. MVP 범위

### 포함

- 혼자 결정: 인원 선택 → 활동 돌림판 → 장소 돌림판 → 지도 연결 → 공유

- 마감 전 득표 실시간 공개
- 투표 수정 기능
- 마이페이지 / 히스토리

- 장소 자체 DB / 리뷰

## 9. UX 원칙

- 10초 안에 결정할 수 있는 흐름
- 로그인 없음 — 혼자 결정, 같이 결정 모두 즉시 사용 (같이 결정은 닉네임 입력만)
- 마감 전 득표 비공개 — 공정한 투표 유도
- 게임처럼 재밌는 인터랙션 (돌림판)
- 동점 시 랜덤 결정 버튼 — 핵심 가치(결정 피로 해소) 유지
- 장소는 선택 사항 — 활동만 결정해도 OK
- 카카오톡 인앱브라우저에서도 공유 작동

## 11. 검증 방법

1. 방장 시나리오: 방 생성 → 초대 링크 복사 → 공유 정상 동작
2. 참여자 시나리오: 링크 접속 → 닉네임 입력 → 투표 → 대기 화면 진입
3. 마감 처리: 마감 시간 도달 시 결과 화면 자동 전환 확인
4. 동점 처리: 동점 결과 시 랜덤 버튼 노출 확인
5. 혼자 결정: 기존 플로우 정상 동작 (로그인 없이)
