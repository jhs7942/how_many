# 몇명이니 (HowMany) — PLAN B 요구사항

> 마지막 업데이트: 2026-03-16 (PLAN B 재설계 — ver_1에서 그룹 결정 서비스로 전환)

## 컨텍스트

기존 ver_1은 개인 사용자가 혼자 조건을 입력해 장소를 추천받는 방식이었다.
PLAN-B는 **인원 선택 → 활동 추천 → 그룹 결정**을 10초 안에 끝내는 것을 목표로,
구현 복잡도를 낮추고 사용자를 빠르게 모을 수 있는 방향으로 재설계한다.

---

## 1. 서비스 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | 몇명이니 (HowMany) |
| 핵심 컨셉 | 모임 결정 피로를 해결하는 인원 기반 활동·장소 추천 서비스 |
| 목표 | 앱 실행 → 10초 안에 결정 |
| 플랫폼 | 모바일 웹 (카카오톡 인앱브라우저 포함) |
| 개발 기간 | 2026.03 ~ 2026.06 |

---

## 2. 해결하려는 문제

- 모임에서 "어디 갈지" 단톡방 30분 토론 → 결국 아무거나
- 정보가 없어서가 아니라, 선택지가 너무 많아서 결정 못함
- 지도·리뷰·예약 앱을 오가며 피로 누적

**핵심 가치:** 검색 서비스가 아닌 결정 서비스

---

## 3. 사용자 흐름 (UX Flow)

```
앱 실행
  └─ Splash
      └─ 홈 (인원 선택)
            ├─ 투표 모드
            │     └─ 로비 (닉네임 입력 + 방 코드 공유)
            │           └─ 제안 입력 화면 (타이머 45초)
            │                 └─ 투표 진행 화면 (타이머 15초)
            │                       └─ 결과 화면
            │                             ├─ 공유하기
            │                             └─ 지도 보기
            │
            └─ 랜덤 돌림판 모드
                  └─ 활동 카테고리 추천 (인원 기반)
                        └─ 돌림판
                              └─ 결과 화면
                                    ├─ 공유하기
                                    └─ 지도 보기
```

## 4. 화면 구성

### 공통
| # | 화면 | 설명 |
|---|------|------|
| 1 | 스플래시 | 앱 로고, 브랜드 태그라인 |
| 2 | 홈 | 인원 선택 버튼 (2명·3명·4명·5명·6명+), 모드 선택 진입 |

### 투표 모드
| # | 화면 | 설명 |
|---|------|------|
| 3 | 로비 | 닉네임 입력, 방 코드 생성, 초대 링크 복사, 참여자 목록, 게임 시작 버튼 |
| 4 | 제안 입력 | 타이머 45초, 장소/활동 자유 입력, 칩 형태 이전 제안 표시, "상관없어요" 선택지 |
| 5 | 투표 진행 | 타이머 15초, 제안 목록 + 이미지 + 투표 수, 득표 현황 바 |
| 6 | 결과 | 최다 득표 활동/장소, 투표 통계, 공유 버튼, 지도 보기 버튼 |

### 랜덤 돌림판 모드
| # | 화면 | 설명 |
|---|------|------|
| 7 | 활동 추천 | 인원 기반 활동 카테고리 카드 표시 (4명이면 → 보드게임·노래방·고깃집 등) |
| 8 | 돌림판 | 활동 카테고리가 세그먼트로 표시된 돌림판, SPIN 버튼, 다시 돌리기 |
| 9 | 결과 | 당첨 활동 강조 표시, 근처 장소 카드, 공유 버튼, 지도 보기 버튼 |

## 5. 기능 상세

### 인원 기반 활동 추천
```
2명  → 카페, 산책, 전시
3명  → 카페, 술집, 보드게임
4명  → 노래방, 보드게임, 방탈출, 볼링
5명+ → 고깃집, 술집, 볼링
```

### 투표 모드 동작 방식
- 방장이 방을 생성 → 링크/코드 공유 (카카오톡 공유 포함)
- 참여자는 닉네임만 입력하면 방 입장 (로그인 불필요)
- 타이머는 클라이언트 기준으로 동작 (실시간 동기화 없음)
- 각자 제안 입력 후 → 각자 투표 → 결과 확인

### 랜덤 돌림판
- 인원 기반으로 추천된 활동 카테고리가 세그먼트로 표시
- 세그먼트 추가/제거 가능
- 스핀 애니메이션 후 결과 강조

### 지도 연결
- 결과 화면에서 "근처에서 보기" 클릭 시 카카오/네이버 지도 새 탭
- 장소 DB 자체 구축 없음 (지도 앱 연결로 대체)

### 공유 기능
- 카카오톡 공유 (Kakao JS SDK)
- 인앱브라우저에서도 동작
- 클립보드 복사 폴백

## 8. UX 원칙

- 10초 안에 결정할 수 있는 흐름
- 로그인 장벽 없음 — 닉네임만으로 즉시 참여
- 게임처럼 재밌는 인터랙션 (돌림판, 타이머)
- 지도는 보조 — 직접 DB 없이 외부 지도 앱으로 연결
- 카카오톡 인앱브라우저에서도 공유 작동
