# 시장 조사: 한국 맛집 랜덤 선택 서비스

## SUMMARY
한국 맛집 랜덤 선택 시장은 크게 두 축으로 나뉜다. (1) 위치 기반 실제 식당 랜덤 뽑기(가챠, 오늘 뭐 먹지?, 랜덤다이닝), (2) 메뉴 카테고리 룰렛(점메추, 뭐먹지?, 메뉴 룰렛 웹). 위치 기반 서비스는 카카오/네이버 API로 데이터를 실시간 조회하며, 메뉴 룰렛은 정적 데이터베이스를 사용한다. 그룹이 함께 결정하는 기능은 아직 어느 서비스도 제대로 구현하지 않은 공백 영역이다. 카카오맵·네이버지도의 AI 추천 기능 강화로 단순 랜덤 선택 앱의 차별화 압력이 커지고 있다.

---

## 조사 배경
- **주제**: 한국 시장 내 맛집 랜덤 선택, 오늘 뭐 먹지 결정 도구
- **타겟 시장**: 한국, 특히 결정 장애를 겪는 MZ세대 및 직장인 그룹
- **조사 일자**: 2026년 4월

## 시장 트렌드

- **트렌드 1 — AI 맞춤 추천으로 이동**: 카카오맵 'AI메이트 로컬'(대화형 장소 추천), 네이버지도 '발견' 탭 등 대형 플랫폼이 AI 기반 개인화 추천을 적극 도입. 단순 랜덤 뽑기 앱은 "광고 없는 순수 랜덤"을 차별점으로 강조해야 생존 가능.
- **트렌드 2 — 결정 피로(Decision Fatigue) 해소가 핵심 니즈**: MZ세대는 고르는 과정에서 소모되는 감정·에너지를 줄이길 원한다. "빠르게 고르기"보다 "스트레스 없이 고르기"가 실제 니즈. AI 추천도 같은 맥락.
- **트렌드 3 — 게임화(Gamification) 강화**: 단순 룰렛에서 월드컵·스크래치·뽑기권 등 게임적 요소 추가가 리텐션에 효과적. 가챠의 뽑기 메타포, 점메추의 메뉴 월드컵이 대표 사례.
- **트렌드 4 — 카카오맵/네이버맵 API 활용 보편화**: 서드파티 개발자들이 카카오 Local API로 반경 내 식당 목록 조회 → 랜덤 선택 구현이 기술적으로 쉬워짐. 진입 장벽 낮아 신규 서비스 지속 등장.
- **트렌드 5 — 숏폼 리뷰·SNS 연동 강화**: 네이버지도·카카오맵 모두 숏폼 리뷰 기능 추가(2024). 맛집 앱에서 콘텐츠 소비와 의사결정이 통합되는 방향.
- **트렌드 6 — 그룹 의사결정 공백**: 여럿이서 "오늘 어디 먹지?" 결정을 함께 할 수 있는 전용 서비스가 한국 시장에 부재. 일반 투표 플랫폼(치즈버튼 등)을 맛집 결정에 임시 활용하는 사례만 존재.

## 공통 UX 패턴

- **패턴 1 — 돌림판(룰렛) 인터페이스**: 거의 모든 메뉴 결정 서비스가 채택. 회전 애니메이션이 "운명에 맡기는" 감각을 주며 결과 수용도를 높임. 폭죽 이펙트 등 결과 축하 연출이 세트로 사용됨.
- **패턴 2 — 지도 기반 범위 선택**: 가챠가 채택한 방식. 지도 화면이 곧 선택 범위가 되어 복잡한 검색·필터 없이 직관적 조작 가능. 지도 드래그 → 뽑기라는 단순한 인터랙션.
- **패턴 3 — 카드 스택 / 월드컵 토너먼트**: 두 선택지를 1:1 비교해 승자를 선택하는 방식(이상형 월드컵 포맷). 결정 과정을 게임처럼 만들어 참여 시간을 늘림.
- **패턴 4 — 상황별 필터 선택 (온보딩)**: 서비스 진입 시 "점심/저녁", "혼밥/회식/데이트", "가격대" 등 상황을 먼저 선택하면 결과 풀이 좁아지는 방식. 선택 부담을 단계적으로 낮춤.
- **패턴 5 — 커스텀 목록 저장 + 랜덤**: "내가 가고 싶은 곳 저장 → 그 안에서 랜덤 뽑기" 패턴(오늘 뭐 먹지?, 뽈레 파생). 개인화된 신뢰 목록에서 결정해 결과 수용도 극대화.
- **패턴 6 — 결과 공유 기능**: 결과를 카카오톡·링크로 공유해 그룹 합의 유도. 메뉴 룰렛 확장판, 가챠 등이 공유 기능 보유.
- **패턴 7 — 로그인 없이 즉시 사용**: 가챠, 뽈레, 메뉴 룰렛 확장판 등 회원가입 장벽을 없애는 것이 전환율에 핵심. 사용자 피드백에서 "로그인 없이 쉽게 사용 가능"이 긍정 요소로 반복 언급.

## 사용자 피드백 요약

**자주 칭찬받는 점**
- 로그인 없이 바로 사용 가능 (마찰 최소화)
- 귀여운 캐릭터·UI 디자인
- 복잡한 필터 없이 직관적으로 결정 가능
- 카카오맵·네이버맵 연동으로 즉시 길찾기 가능
- "결정 스트레스를 없애준다"는 본질적 가치

**자주 불만인 점**
- 추천 결과에 광고·협찬 맛집이 섞이는 것에 대한 불신
- 실제 영업 여부 확인 불가 (현재 영업시간 미반영)
- 메뉴만 추천하고 실제 식당과 연결되지 않는 서비스에 대한 아쉬움
- 혼자서만 사용 가능, 여럿이서 함께 결정하는 기능 부재
- iOS/Android 한쪽만 지원하는 서비스 다수

**자주 요청되는 기능**
- 여러 명이 동시에 참여해 함께 뽑기/투표하는 기능
- 가격대·거리 필터 조합
- "이미 간 곳 제외" 방문 이력 관리
- 실시간 영업 여부 확인
- 결과를 카카오톡으로 바로 공유

## 차별화 기회

- **기회 1 — 그룹 공동 결정 특화**: 현재 한국 시장에서 여럿이서 실시간으로 맛집을 함께 결정하는 전용 서비스가 없다. "방 만들기 → 초대 → 각자 필터 입력 → 교집합에서 랜덤 뽑기" 또는 "후보 제안 → 투표 → 최다 득표 또는 룰렛 결선" 흐름은 친구 그룹, 팀 회식 등 반복 니즈가 있는 고빈도 시나리오다. how_many의 Group 플로우가 직접 연결되는 영역.
- **기회 2 — 실제 식당 연결 없는 메뉴 룰렛의 한계 극복**: 대부분의 메뉴 룰렛은 "짜장면"처럼 메뉴 카테고리만 알려주고 끝난다. 카카오 Local API 또는 네이버 플레이스 API를 연동해 "짜장면 → 현재 위치 반경 500m 짜장면 식당 랜덤 1곳"으로 자연스럽게 연결하면 즉각적인 실용성이 생긴다.
- **기회 3 — "광고 없는 순수 랜덤" 신뢰 포지셔닝**: 카카오맵·네이버지도는 검색 결과에 광고가 섞이고, AI 추천은 사용자가 알고리즘을 신뢰하지 않는 경향이 있다. 완전 랜덤(광고·협찬 없음)을 전면에 내세우는 포지셔닝은 해당 불신층을 흡수할 수 있다. 가챠가 이 방향으로 메시지를 사용 중이나, 브랜드 인지도가 낮다.
- **기회 4 — 소규모 그룹 소셜 공유 루프**: 결과를 카카오톡으로 공유했을 때 수신자가 바로 참여할 수 있는 링크 기반 그룹 참여 플로우. "나는 결정했는데 너는 어때?" 형태의 소셜 바이럴 루프가 자연스러운 리텐션 메커니즘이 된다.
- **기회 5 — 방문 이력 기반 "새로운 곳만 추천"**: 이미 간 식당은 제외하고 새로운 곳만 랜덤 추천하는 기능. 사용할수록 더 유용해지는 리텐션 구조를 만들 수 있다. 현재 어떤 서비스도 이를 제대로 구현하지 않음.

## 데이터 확보 방법 분석

한국 시장에서 맛집 데이터를 확보하는 주요 방법:

| 방법 | 대표 서비스 | 장점 | 단점 |
|------|------------|------|------|
| **카카오 Local API** | 가챠, 서드파티 다수 | 무료, 실시간, 위치·카테고리·영업시간 제공, 결과에 카카오맵 연동 | 요청 제한, 카카오 의존성 |

| **정적 메뉴 DB** | 점메추, 메뉴 룰렛 | 서버 불필요, 빠름 | 실제 식당 연결 불가 |
