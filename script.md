Create a beautiful mobile-first wireframe for a lifestyle web app called "몇명이니? (HowMany)".

This app helps users quickly decide where to go for a group gathering based on group size, location, and mood.
The core value is not search, but fast decision-making.

Please design the app with a warm, minimal, and emotionally appealing visual direction.
It should feel like a modern lifestyle recommendation app, not a generic SaaS tool.

## Visual style
- warm neutral color palette
- creamy white background
- soft beige, light olive, muted warm gray accents
- rounded cards
- elegant and airy spacing
- clean typography
- image-driven recommendation cards
- calm, polished, premium feeling
- minimal but charming interface
- soft shadows
- mobile app-like UI

## Avoid
- generic corporate SaaS design
- overly gray boxy layout
- admin dashboard feel
- cluttered screens
- heavy borders
- cold technical interface

## Include the following screens

1. Splash screen
- app logo
- short brand tagline
- warm and clean first impression

2. Onboarding screen 1
- explain that users can quickly decide where to go
- simple illustration or visual
- short copy, emotionally appealing

3. Onboarding screen 2
- explain group-size-based recommendation
- highlight quick decision and easy comparison

4. Onboarding screen 3
- explain random recommendation feature as a fun optional tool
- soft and playful, but still minimal

5. Sign up / Login screen
- simple and elegant layout
- options for email login, social login
- minimal input fields
- easy CTA buttons

6. Home screen
- service intro
- group size selection
- location selection
- mood/category selection
- primary CTA button
- recent popular choices section

7. Condition selection screen
- select group size
- select district/location
- select mood
- selected summary section
- continue button

8. Recommendation result screen
- top summary of selected conditions
- beautiful place cards with image, place name, category, short reason, distance
- clear CTA buttons
- map as secondary element

9. Random decision screen
- visually pleasing card reveal interaction
- one randomly selected place
- "try again" and "choose this place" buttons

10. Place detail screen
- large hero image
- place name
- category / mood / group fit
- short recommendation summary
- location info
- reservation CTA

11. Empty result screen
- elegant empty state
- retry CTA
- similar recommendations section

Please make the wireframes low-to-mid fidelity, but visually refined and aesthetically pleasing.
The result should feel like a real portfolio-worthy product concept for a modern Korean lifestyle app.
