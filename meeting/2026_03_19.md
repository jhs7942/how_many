# 2026-03-19 버그 리포트

## 발견된 오류 목록

### 1. 참여하기 — 방코드 입력 후 방장으로 진입되는 오류
- **증상**: 참여자가 6자리 코드 입력 후 입장 시 방장(host) 권한으로 처리됨
- **관련 플로우**: `홈 → [참여하기] → 6자리 코드 입력 → 대기실`
- **기대 동작**: participants 테이블에 `방장여부 = false`로 삽입, 대기실에서 시작 버튼 비활성화

---

### 2. 야바위 — 시작 시 하단에 컨텐츠 마크가 노출되는 오류
- **증상**: 야바위 시작 시 화면 하단에 컨텐츠(후보) 마크가 뜬금없이 렌더링됨
- **관련 기능**: 야바위 셔플 애니메이션 시작 시점 UI
- **기대 동작**: 셔플 중에는 컵만 표시, 컨텐츠 정보는 컵 선택 후 결과 확인 시에만 노출
- **첨부**: 이미지 참고
야바위 -> 컨텐츠 셔플
---

### 3. 야바위 — 결과에서 꽝이 나오는 오류
- **증상**: 야바위 결과 선택 시 꽝(빈 결과)이 반환됨
- **관련 스펙**: `컵 수 = 후보(컨텐츠) 수 — 빈 컵 없음, 각 컵이 곧 컨텐츠` (plan.md §5)
- **기대 동작**: 컵 선택 시 반드시 후보 중 하나가 결과로 나와야 함, 꽝 없음

---

### 4. 결과 공유하기 — 실제 결과 페이지로 미이동
- **증상**: 결과 공유하기 버튼이 실제 결과 페이지(`/result/[id]`)로 이동하지 않음
- **관련 스펙**: `결과를 DB에 저장 → 고유 URL(/result/[id]) 생성` (plan.md §5 결과 공유)
- **기대 동작**: 공유 링크 클릭 시 `/result/[id]` 페이지로 정상 이동

---

### 5. 돌림판 — 표시 결과값과 실제 결과값 불일치
- **증상**: 돌림판이 멈춘 위치와 최종 결과로 표시되는 값이 다름
- **관련 기능**: SpinWheel 결과 인덱스 계산 로직
- **기대 동작**: 돌림판 정지 세그먼트 = 결과 화면에 표시되는 값 일치

---

### 6. 결과 화면 — 홈으로 돌아가기 버튼 없음 / 돌림판 화면 뒤로가기 버튼 없음
- **증상**:
  - 랜덤 추천 결과 화면에서 홈으로 돌아가기 버튼이 사라짐
  - 돌림판(야바위) 화면에서 뒤로가기(BackButton) 없음
- **기대 동작**: 결과 화면에 홈 이동 버튼 표시, 랜덤 화면에 뒤로가기 버튼 표시

---

### 7. 랜덤의 랜덤 — 재회전 시 최초 결과값 고정 오류
- **증상**: 돌림판 재회전(50% 확률) 후 최초 결과값이 그대로 최종 결과로 고정됨
- **관련 스펙**: `돌림판 결과 후 50% 확률로 자동 재회전, 현재 결과 보여준 뒤 0.5초 후 좌/우 랜덤 방향으로 재회전` (plan.md §5)
- **기대 동작**: 재회전 후 새로 멈춘 세그먼트가 최종 결과로 반영되어야 함
